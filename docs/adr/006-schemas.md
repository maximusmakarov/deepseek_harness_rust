# 006. schemars + jsonschema

- **Статус:** Accepted
- **Дата:** 2026-11-12

## Контекст

Схемы инструментов и конфига должны генерироваться из типов и валидироваться.

## Решение

`schemars` для генерации JSON Schema, `jsonschema` для валидации аргументов; критичные поля проверяются вручную.

## Последствия

Единый источник правды; схемы нужно держать стабильными, иначе ломается кэш промпта.

## Альтернативы

- Оставить как в DSH Desktop — отклонено: другой рантайм и/или несовместимый ABI.
- Отложить решение — отклонено: блокирует M0/M1.
