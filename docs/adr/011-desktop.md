# 011. Desktop — Tauri над `dshr serve`

- **Статус:** Accepted (реализовано 13.11.2026)
- **Дата:** 2026-11-12

## Контекст

DSH Desktop — тонкий Electron-host; мы не тащим Chromium.

## Решение

Tauri-оболочка запускает `dshr serve` на loopback и грузит тот же Web UI; desktop не добавляет второй протокол и не отдаёт нативные API в страницу.

## Последствия

Малый размер и один протокол; зависимость от системного webview и различия ОС. Оболочка: `crates/desktop`, loopback-сервер со случайным портом и токеном, токен в URL → `localStorage`; `--check` проверяет запуск без окна. Трей/автообновление/бандл — следующий срез.

## Альтернативы

- Оставить как в DSH Desktop — отклонено: другой рантайм и/или несовместимый ABI.
- Отложить решение — отклонено: блокирует M0/M1.
