# 005. tokio + mpsc-актор журнала

- **Статус:** Accepted
- **Дата:** 2026-11-12

## Контекст

Запись событий должна быть сериализована, чтение — параллельным.

## Решение

Один writer-актор на сессию, broadcast-подписка для читателей, `CancellationToken` на turn/step, семафор на инструменты.

## Последствия

Предсказуемый порядок `seq`; актор — точка сериализации и потенциальное узкое место.

## Альтернативы

- Оставить как в DSH Desktop — отклонено: другой рантайм и/или несовместимый ABI.
- Отложить решение — отклонено: блокирует M0/M1.
