# 014. Инструменты, approvals и агентный цикл

- **Статус:** Accepted
- **Дата:** 2026-11-12

## Контекст

M1 умел один запрос к модели. Для агентной работы нужны инструменты, проверка аргументов, политика доступа и цикл, который исполняет tool-calls и возвращает результаты модели. Политика должна работать и в headless-режиме, и в TUI с интерактивным подтверждением.

## Решение

1. **Один реестр** (`dshr-tools`) с трейтом `Tool`: имя, описание, JSON Schema, `execute(&ToolCtx, args)`.
2. **Пайплайн:** валидация аргументов по схеме → approval → выполнение → ограничение вывода. Большой вывод пишется в spill-файл, в контекст попадает усечённый фрагмент и путь.
3. **Политика** (`ApprovalPolicy`): режимы `read-only`, `workspace-write`, `danger-full-access`; чтение и поиск разрешены всегда; запись внутри workspace — автоматически в `workspace-write`; bash и запись вне workspace — через `Approver`.
4. **Отказ не рушит turn:** запрещённый вызов превращается в `tool_result` с `is_error=true`; модель видит причину и может выбрать другой путь.
5. **Агент** (`dshr-agent`) владеет turn/step-циклом, пишет события в журнал (`assistant_message`, `tool_result`, `turn_end`) и уведомляет наблюдателя о тексте и жизненном цикле инструментов.
6. **TUI** получает approval через oneshot-канал и показывает модалку; headless использует `AutoApprover` (`--yes`/`--danger`) или `DenyApprover`.

## Последствия

- Инструменты не знают про UI и про то, как принимается решение; политика и UI заменяемы.
- Схемы — поддерживаемое подмножество JSON Schema (объекты, required, типы, enum, границы), а не полный стандарт.
- `bash` убивает процесс при таймауте/отмене через `kill_on_drop`, но не создаёт отдельную process group; persistent-сессии и `apply_patch`/`ask_user` отложены.
- Отказы и spill-файлы попадают в журнал/аудит, что упрощает разбор инцидентов.

## Альтернативы

- Выполнять инструменты без approvals — отклонено: недопустимый риск для записи и shell.
- Полный `jsonschema` — отложено: тяжёлая зависимость ради схем, которые мы сами пишем.
- Инструменты как WASM-плагины — будущий тир; встроенные инструменты остаются крейтами.
