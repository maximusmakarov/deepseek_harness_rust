# 009. Сеть и exec в политике песочницы

- **Статус:** Accepted
- **Дата:** 2026-11-12

## Контекст

DSH `SandboxMode` покрывает только файловые эффекты; нам нужны сеть и запуск процессов.

## Решение

`SandboxPolicy` расширяет файловый режим полями `network` и `exec`; это осознанное расширение, документируется отдельно.

## Последствия

Более полная модель угроз; больше поверхности атаки и ответственности.

## Альтернативы

- Оставить как в DSH Desktop — отклонено: другой рантайм и/или несовместимый ABI.
- Отложить решение — отклонено: блокирует M0/M1.
