# 004. JSONL — истина, SQLite — индекс

- **Статус:** Accepted
- **Дата:** 2026-11-12

## Контекст

Журнал должен переживать `kill -9`, а поиск — работать быстро.

## Решение

Источник истины — append-only JSONL с fsync на границе turn; SQLite (WAL, FTS5) — перестраиваемый индекс, не источник данных.

## Последствия

Простое восстановление и аудит; дублирование данных и необходимость переиндексации.

## Альтернативы

- Оставить как в DSH Desktop — отклонено: другой рантайм и/или несовместимый ABI.
- Отложить решение — отклонено: блокирует M0/M1.
