# 003. TUI сейчас, Web на Leptos, Tauri позже

- **Статус:** Accepted
- **Дата:** 2026-11-12

## Контекст

Нужны три поверхности без дублирования логики и без Electron.

## Решение

TUI на ratatui в T1; HTTP/WS API на axum; Web UI на Leptos в T2; desktop — тонкая Tauri-оболочка над `dshr serve` в T3.

## Последствия

Mono-Rust и общие типы; меньше готовых UI-компонентов, зрелость Leptos проверяется в M6.

## Альтернативы

- Оставить как в DSH Desktop — отклонено: другой рантайм и/или несовместимый ABI.
- Отложить решение — отклонено: блокирует M0/M1.
