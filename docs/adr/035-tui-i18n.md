# 035. TUI i18n: ru/en

- **Статус:** Accepted
- **Дата:** 2026-11-13

## Контекст

TUI содержит русские подсказки/approval, CLI — английские. Нужен выбор языка без переписывания всех сообщений.

## Решение

1. Конфиг `ui.language: ru | en` (default `ru`).
2. Крейт `dshr-i18n`: `Lang`, `hint`, `approval`, `thinking`, `done`.
3. TUI использует выбранный язык; CLI/справка и вывод команд пока не локализованы.

## Последствия

- Переключение языка TUI без пересборки.
- Смешанный язык CLI/TUI остаётся; полная i18n — отдельный срез.

## Альтернативы

- Fluent/gettext — отложено: строк мало, зависимость не оправдана.
