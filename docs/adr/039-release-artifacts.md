# 039. Релизные артефакты: архивы, контрольные суммы и подпись

- **Статус:** Accepted
- **Дата:** 2026-11-13

## Контекст

HEAD-формула, systemd/launchd и Dockerfile покрывали установку из исходников, но не
давали стабильных бинарных артефактов, контрольных сумм и проверяемой подписи. Без
этого пользователь либо собирает всё сам, либо доверяет скачанному бинарю без
проверки.

## Решение

1. **Детерминированные архивы:** сортировка файлов, mtime/uid/gid = 0, gzip-заголовок с нулевым временем; одинаковый бинарь даёт одинаковый `.tar.gz` и sha256. Бинарная воспроизводимость сборки отдельно не гарантируется.
2. **Архивы на тег `v*`:** `dshr-<version>-<target>.tar.gz` для
   `x86_64/aarch64-apple-darwin`, `x86_64/aarch64-unknown-linux-gnu` и
   `x86_64-pc-windows-msvc`; внутри бинарь, README и лицензии.
3. **`SHA256SUMS`** объединяет суммы всех архивов и публикуется в релизе; установщик
   `scripts/install.sh` проверяет сумму до распаковки.
4. **Ed25519-подпись** `SHA256SUMS.sig` и публичный ключ `SHA256SUMS.pub`, если в
   репозитории задан `DSHR_RELEASE_KEY`. Подпись — отделённая (detached), без
   встраивания в архивы; проверка: `dshr release verify`.
5. **Provenance:** каждый архив аттестуется GitHub
   `actions/attest-build-provenance` (Sigstore/OIDC), проверка —
   `gh attestation verify <archive> --repo <owner>/<repo>`.
6. **Бинарная Homebrew-формула** рендерится из `SHA256SUMS`
   (`scripts/render-formula.sh`) и публикуется как `dshr.rb`; это не ghcr-бутылка,
   но установка идёт из подписанного релиза с закреплённым `sha256`.
7. **Ключи:** приватный ключ живёт только в GitHub Secret; `keygen` пишет файл с
   правами `0600`. Публичный ключ релиза публикуется рядом с `SHA256SUMS`.

## Последствия

- Установка без Rust: скачать архив или применить `dshr.rb`, проверить сумму.
- Подпись не решает bootstrap-проблему: проверять её нужно уже доверенным бинарём
  или независимой реализацией Ed25519.
- Архивы детерминированы; release-сборка использует `SOURCE_DATE_EPOCH=0`, `CARGO_INCREMENTAL=0` и remap путей, поэтому бинарь воспроизводим при том же toolchain (проверено `scripts/check-reproducible.sh`). Homebrew-бутылки публикуются как release-ассеты с `bottle do` (root_url — GitHub Releases); ghcr-бутылок нет.

## Альтернативы

- Только `cargo install` — отвергнуто: требует Rust и не даёт стабильного бинаря.
- minisign/cosign вместо собственной подписи — возможно позже; сейчас Ed25519 уже
  есть в проекте и не добавляет внешнего toolchain.
- ghcr-бутылки через `brew test-bot` — отложено: нужен отдельный CI-контур Homebrew.
