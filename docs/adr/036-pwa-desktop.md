# 036. Desktop через PWA, Tauri отложен

- **Статус:** Accepted
- **Дата:** 2026-11-13

## Контекст

DSH Desktop — Electron-приложение. Для dshr нужен desktop-сценарий, но Tauri требует отдельного GUI-проекта и системного WebKit, которого нет в headless-CI.

## Решение

1. Web UI получает **PWA-манифест** и иконки, `display: standalone`.
2. Установка — из браузера поверх `dshr serve`; отдельного бинарника нет.
3. **Tauri** не добавляется в workspace и CI; отложен до появления GUI-пайплайна.

## Последствия

- Desktop-сценарий доступен без Electron/Tauri.
- Нет офлайн-режима, автозапуска и нативных меню.
- PWA использует тот же token/API, что и Web UI.

## Альтернативы

- Tauri — отложено: отдельный проект, WebKit в Linux CI.
- Electron — отклонено: противоречит цели лёгкого Rust-бинарника.
