# 008. Счётчик токенов

- **Статус:** Accepted
- **Дата:** 2026-11-12

## Контекст

Порог compaction нужен до первого ответа, а точный usage приходит только после.

## Решение

`usage` провайдера после ответа + локальная оценка до запроса (`tiktoken-rs`/`tokenizers`); расхождение калибруется.

## Последствия

Работает офлайн и до первого ответа; два источника требуют калибровки.

## Альтернативы

- Оставить как в DSH Desktop — отклонено: другой рантайм и/или несовместимый ABI.
- Отложить решение — отклонено: блокирует M0/M1.
