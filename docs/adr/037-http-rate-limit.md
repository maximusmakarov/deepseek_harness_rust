# 037. HTTP rate limit per token

- **Статус:** Accepted
- **Дата:** 2026-11-13

## Решение

`serve --rate-limit N` / `DSHR_RATE_LIMIT`: фиксированное окно 60 с, N запросов на bearer-токен; неавторизованные — общий bucket. `/v1/health` исключён. Ответ `429` + `Retry-After: 60`.

## Границы

In-memory, один инстанс; нет распределённого лимита и разных лимитов по эндпоинтам.
