# 012. YAML-парсер: serde-saphyr

- **Статус:** Accepted
- **Дата:** 2026-11-12

## Контекст

`serde_yaml_ng` тянет `unsafe-libyaml`, для которого нет сопровождающего: RUSTSEC-2024-0449 (unmaintained). `cargo deny` блокирует сборку, а заменять парсер на этапе M0 дешевле, чем позже.

## Решение

Используем `serde-saphyr` 2.1: безопасный Rust-парсер с прямой десериализацией в `serde_json::Value`, поддержкой сериализации и точными ошибками. YAML остаётся форматом конфигурации, JSON — внутренним представлением для слияния слоёв.

## Последствия

- Supply chain чище: нет `unsafe-libyaml` и `serde_yaml`.
- MSRV проекта поднят до 1.89 (требование `serde-saphyr`).
- Формат вывода `config show` проверяется тестами; при смене парсера — golden-тест.

## Альтернативы

- `serde_yaml_ng` + ignore RUSTSEC-2024-0449 — отклонено: скрывает необслуживаемый unsafe-код.
- `yaml-rust2` + ручная конвертация в JSON — отклонено: больше кода ради того же результата.
