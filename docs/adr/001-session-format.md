# 001. Свой формат сессий

- **Статус:** Accepted
- **Дата:** 2026-11-12

## Контекст

DSH хранит журнал как версионированный JSONL; нам нужен формат, который мы контролируем и можем мигрировать без оглядки на 0.2.x.

## Решение

Свой `session.v1.jsonl.zstd`: append-only события, numbered generations, цепочка миграций `vN -> vN+1`. Импорт DSH-сессий — отдельный адаптер, не основной путь.

## Последствия

Полный контроль эволюции и производительности; нет прямой совместимости с DSH-инструментами чтения журнала.

## Альтернативы

- Оставить как в DSH Desktop — отклонено: другой рантайм и/или несовместимый ABI.
- Отложить решение — отклонено: блокирует M0/M1.
